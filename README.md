# AlSandooq - صندوق أم تريبات التكافلي

تطبيق لإدارة الفزعات والاشتراكات لأهل أم تريبات.

المشكلة الحالية: الفزع بنزل في قروب واحد من قروبات الحلة الاربعة وما بصل الباقي.

الحل:
1. تطبيق واحد فيهو كل الناس
2. تسجيل عضو برقم تلفون ورقم عضوية
3. دفع اشتراك عبر بنكك
4. طلب فزع مع تقرير طبي
5. كشف حساب شفاف

التقنية: Flutter + Firebase
الترخيص: مجاني لأهل الحلة

لجنة مقترحة: رئيس + امين مال + مسجل عضوية + مراجعين من كل قروب.
